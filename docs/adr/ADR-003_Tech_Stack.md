# ADR-003: Вибір стеку Node.js + React + TypeScript

## Статус
Accepted

## Контекст
Система вимагає інтерактивного інтерфейсу (динамічна схема вагонів) та швидкої відповіді сервера при перевірці доступності місць. Команда має досвід роботи з екосистемою JavaScript.

## Рішення
Backend: Node.js (Express.js) + TypeScript.
Frontend: React + Vite.

## Обґрунтування
1. TypeScript: Дозволяє уникнути помилок при типізації даних квитків та пасажирів на етапі написання коду.
2. Екосистема npm: Наявність готових бібліотек для генерації PDF-квитків та роботи з платіжними шлюзами.
3. React: Найкращий вибір для створення інтерактивної схеми вибору місця у вагоні.

## Альтернативи
- Python (Django): Відхилено через нижчу швидкість обробки асинхронних запитів у порівнянні з Node.js для даного типу задач.

## Наслідки
### Позитивні
- Висока швидкість розробки UI.
- Використання однієї мови на обох кінцях системи (Full-stack JS).
### Негативні
- Велика кількість залежностей у проєкті.
